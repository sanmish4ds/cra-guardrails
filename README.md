# Stateful Guardrails for Multi-Turn LLM Systems: A Conversational Risk Accumulation Framework

Code, benchmark data, and results for the CRA paper.

## Layout

| Path | Contents |
|---|---|
| `experiments/` | Protocol, baseline, and ablation scripts (`run_cra_*`, `run_cranet*`, `run_judge_*`, `run_llamaguard_*`, `run_s3_*`, …) |
| `experiments/generate_cra_bench_v01.py` | CRA-Bench v0.1 generator |
| `experiments/prompts/` | LLM-judge prompt |
| `experiments/results/` | Result JSONs reported in the paper |
| `data/cra_bench_*` | CRA-Bench v0.1 / v0.2 / v0.3 (3- and 5-family variants) |
| `data/human_cra_transfer/` | Human-session transfer set |
| `paper/figures/` | CRA figures (ROC, ablation, per-category, TTD) |
| `integration/cra-telemetry.js` | Reference Node.js session telemetry used in the SQL-assistant deployment |

Scripts resolve paths relative to the repo root, so run them from here.

## Setup

```bash
python3 -m pip install -r experiments/cra-requirements.txt   # or environment-pinned.txt for exact versions
python3 -m spacy download en_core_web_sm
cp .env.example .env   # fill in API keys for judge baselines
```

Llama Guard / S3 steps need Ollama with `llama-guard3:1b`.

## Reproducing

```bash
./experiments/run_fast.sh                 # quick multiseed check
./experiments/run_s3_rerun_protocols.sh   # full S3 gate + protocol rerun
```

See `experiments/S3_RERUN_CHECKLIST.md` for the full sequence.

`experiments/models/` (S3 DistilBERT classifier, ~255 MB) and `experiments/cache/` are not committed; they are regenerated by `train_s3_refusal_classifier.py` and `signal_cache.py`.
